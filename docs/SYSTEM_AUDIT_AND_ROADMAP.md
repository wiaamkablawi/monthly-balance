# מיפוי מערכת + Roadmap לשדרוג משמעותי

## 1) מצב נוכחי (As-Is)
- **טכנולוגיה**: React + Vite + TypeScript + Firebase Auth/Firestore.
- **מסכים מרכזיים**:
  - דשבורד חודשי (KPI + גרפים + הוספה/עריכה/מחיקה).
  - מסך תנועות עם עריכה ומחיקה (כולל Swipe במובייל).
  - מסך הגדרות בסיסי.
  - התחברות Google.
- **יכולות ליבה**:
  - הכנסות, הוצאות משתנות, הוצאות קבועות (כולל פריסה לתשלומים).
  - סיכום חודשי + גרפים.
  - שמירת נתונים ב-Firestore.

## 2) פערים מרכזיים
- אין מנוע העדפות משתמש (Theme/צפיפות/הדגשות).
- אין שכבת סינון/חיפוש מתקדמת בתנועות.
- מסך הגדרות דל יחסית ולא מפעיל יכולות אמיתיות.
- אין תוכנית מוצר מסודרת ל-90 יום.

## 3) מה הוספנו בסבב הזה (Now)
1. **מערכת העדפות משתמש מלאה**:
   - Theme: בהיר/כהה/אוטומטי.
   - מצב קומפקטי.
   - הדגשת הוצאות גבוהות.
2. **שדרוג משמעותי למסך תנועות**:
   - סינון לפי סוג תנועה.
   - חיפוש חופשי (קטגוריה/תיאור/תאריך).
   - KPI מהיר על הרשימה המסוננת (הכנסות/הוצאות/נטו/כמות).
   - Empty state ברור כאשר אין תוצאות.
3. **שדרוג UX להדר**:
   - שם המסך מוצג בכותרת.
   - אפשרות לאקשן עליון (כמו התנתקות) ללא כניסה לתוכן.

## 4) 1000 צעדים קדימה - תוכנית פרקטית בשלבים

### שלב A (שבוע 1-2): חוויית משתמש
- Smart onboarding עם הסבר קצר על KPI וקטגוריות.
- קיצורי מקלדת (הוספה מהירה, חיפוש, מעבר חודש).
- תיקוף קלט חכם בזמן אמת + הודעות שגיאה ידידותיות.

### שלב B (שבוע 2-4): אוטומציה וחוקים
- Auto-categorization לפי מילון תיאור/בית עסק.
- חוקים חודשיים (למשל: כל עסקה מ"סופר" -> מזון).
- תבניות הוצאה/הכנסה חוזרות.

### שלב C (חודש 2): תובנות ו-AI
- חיזוי סוף חודש מול תקציב.
- זיהוי חריגות ביחס ל-3 חודשים אחרונים.
- תובנות אוטומטיות: "הוצאות בילוי עלו ב-18%".

### שלב D (חודש 3): מוצר בשל
- Multi-user collaboration עם הרשאות.
- ייצוא PDF/Excel מתקדם + דוחות חודשיים מובנים.
- התראות Push / WhatsApp / מייל על חריגות.

## 5) KPIs מוצעים למדידת הצלחה
- זמן להזנת תנועה חדשה < 12 שניות.
- ירידה בטעויות קטגוריה ב-40%.
- עלייה של 25% בשימוש שבועי פעיל (WAU).
- 90% מהמשתמשים מגדירים לפחות העדפה אחת במסך הגדרות.
